E02-228 is no longer written to log files. Today an import that meets a value not on an attribute's list of **Allowed values** says so in words: a product is imported without that field's value, and a custom entity record is not imported at all.

## What the log file says

| You imported | Severity | Message |
| --- | --- | --- |
| Products | Warning | *The record was imported without this field's value. "Blue" isn't one of this field's options. Change the value in the file, or add the option to the field, and import again.* |
| Custom entity records | Error | *Couldn't import the record. "Blue" isn't one of this field's options. Change the value in the file, or add the option to the field, and import again.* |

The quoted value is the one from your file. In the message, "options" means the entries on the **Allowed values** list.

For a custom entity record the import updates, the quoted value can be one the record already holds, from before it was taken off the list. The record is refused until the file gives the field an allowed value or empties it, or you put the value back on the list. Where to find the log file, and what its columns show: [Reading a log file](/en/troubleshooting/background-jobs.html#reading-a-log-file).

## Fix it

Only a **Text** attribute has a list of allowed values. Choose by whether the value is right and the list is missing it, or the value is wrong.

| The value is… | Fix | Where |
| --- | --- | --- |
| Right, and should be one of the allowed values | Add it to the list | The attribute's **Values** tab: type it under **New value** and select **Add** |
| Right, and the attribute should take any value | Turn on **Allow custom values** | The attribute's **Values** tab, in the **Options** section |
| Wrong, in a file you import by hand | Replace it in the file with one of the allowed values | Your import file |
| Wrong, in files a data source imports for you | Convert or remove it before it is written | The dataset's **Mapping** tab on the data source: open the field's pipeline with the arrow button beside it (pointing at it shows **Edit pipeline**) and add a node that converts or removes the value |

The attribute's **Values** tab is in **Settings → Attributes & sections** for an attribute of a product, and in **Settings → Custom entities** for an attribute of a custom entity — see [Attributes](/en/concepts/attributes.html) and [Custom entity settings](/en/concepts/custom-entities.html#custom-entity-settings). A change on the tab is saved only when you select **Done** in the attribute's window and then **Save** on the section or the custom entity.

Then import the file again.
