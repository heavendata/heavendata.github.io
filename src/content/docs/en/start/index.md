Your first half hour with heavendata. [Sign up](/en/start/sign-up.html) if you haven't yet.
Then start with the setup option you chose when the account was created, and plan the
structure your catalog needs before you load data into it — a little thought here saves a
lot of re-import later.

If you already have products in the system and want to change them, go to
[Products](/en/products.html). If you are trying to get data in or out, go to
[Importing data](/en/import.html) or [Channels & feeds](/en/channels.html).
