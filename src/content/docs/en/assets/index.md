Assets are the files you keep in heavendata: images, PDFs and any other file. They
are either assigned to products or kept in folders in the cloud drive.

## Folders in the cloud drive

The cloud drive keeps the files that are not assigned to products, in folders you
create. Open it from the sidebar: **Catalog** > **Cloud drive**.

**A folder name is used once in each folder.** Two folders in the same folder
can't have the same name. Case matters: `Photos` and `photos` are two different
names and can sit side by side. Files can share a name.

| What you do | What happens when the name is taken |
|--|--|
| Create a folder with **New folder**, or rename one with **Rename** | The folder isn't created or renamed, and a message names the folder that already exists. Choose a different name. |
| Move a folder with **Move to folder** into a folder that already has a folder of that name | The whole move is refused and nothing is moved, including the other files and folders you selected. Rename one of the two folders and try again. |
| Upload with **Add folders** | Nothing is refused. Files go into the folder of that name that is already there, and a missing folder is created. |

**A folder can't be moved into itself or into a folder inside it.** In **Move to
folder**, the folders you are moving are grayed out, so you can't choose them or a
folder inside them. If such a move is made anyway, for example while someone else
moves folders at the same time, it is refused, a message says why, and nothing is
moved. Choose another folder. Of two moves that would put two folders inside each
other, one is refused, so neither folder is lost.

A move can also fail with *Couldn't move the assets. Try again, and contact support
if it fails again.* when many folder moves in your account are waiting. Nothing was
moved; try again in a moment.
